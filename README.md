# 明日方舟萨卡兹肉鸽拟态分队识别器

这个原型用于识别萨卡兹肉鸽商店中是否正在出售 `去伪存真藏品表 哲版` 里的六星藏品。
使用了[MaaFramework](https://github.com/MaaXYZ/MaaFramework), 实现了对游戏商店的识别和操作。

数据来自 [哲三集批宝典](https://docs.qq.com/sheet/DUFhxeHFCaXJwS0Vl?tab=00000d)


## 使用

打开

```
sakazi_shop_detector.exe
```

进入游戏商店界面后，点击窗口里的“开始识别”。

## 注意

务必不要点击藏品或分队图标遮挡商店物品，否则会识别错误！
